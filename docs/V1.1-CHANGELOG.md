## v1.1 — T4: Partner can start/stop contractions from their device

Completed: 2026-06-12 12:11
Status: SHIPPED (code complete; live deploy pending VPS SSH recovery)

### Changes
- luna-relay/server.js:
  - New `contraction_events` table (id, share_id, type, timestamp_ms, author_client_id, created_at) with index on (share_id, timestamp_ms)
  - New `POST /api/shares/:code/event` endpoint:
    - Accepts `{type: "start"|"stop", timestamp?, authorClientId?}`
    - Authorizes only on 'full' or 'track' mode; 'stats' (friends) → 403
    - Rejects bad type → 400; missing share → 410; revoked/expired → 410
    - On success, re-derives the contractions snapshot from the event log and stores it (so existing /contractions pulls see the same shape)
    - Broadcasts an `event` SSE message with `eventType`, `timestamp`, `authorClientId`, plus the derived `current` state
  - Helper `deriveSnapshotFromEvents(code)`: walks the event log in timestamp order, opens contractions on 'start' (ignoring duplicate starts while one is open — conflict resolution: keep earlier), closes on 'stop' (ignoring orphan stops), rejects stops with negative duration
  - Rate limit: 30 events/min per IP for the new endpoint
  - RATE_LIMITS dispatch now matches the new path
- src/lib/relay.ts:
  - New `postContractionEventToRelay(code, event)` helper, returns the full derived snapshot
  - New `ContractionEvent` and `ContractionEventResponse` types
  - 403 from relay returns null (graceful — partner share in stats mode)
- src/components/ShareView.tsx:
  - New `currentContraction` state, populated by the polling tick and the SSE `event` message handler
  - New `isHost` derived from `localStorage["olive:share-owner:<code>"]` — a phone that didn't create the share is treated as a viewer
  - New `canAuthorEvents` (mode !== 'stats' && !isHost) and `eventInFlight` state
  - New "Time this contraction" card with Start/Stop button:
    - Hidden for the host (they have their own timer on the main app)
    - Hidden for 'stats' mode (friends)
    - Hidden when share is archived or postpartum > 24h (read-only keepsake)
    - Renders elapsed time during an in-progress contraction
    - Shows "Started by you" or "Started by partner" attribution
  - New `handleSendEvent`: posts the next event, optimistically updates local state, falls back to error pill on network failure
  - SSE `onmessage` now also handles the `event` type and re-pulls `/contractions` to reconcile
- src/components/ShareSheet.tsx:
  - When `createShareOnRelay` succeeds, set `localStorage["olive:share-owner:<code>"] = "1"` so the host's other devices know not to render the partner button

### Verified (local relay on port 3030)
- Created share in `track` mode, partner-1 starts at T0 → current = {start: T0, author: partner-1}
- host-2 starts at T0+5000 (duplicate, ignored) → current unchanged

- GET /contractions returns the derived snapshot (same shape legacy clients expect)
- 'stats' mode POST /event → 403
- Bad type → 400
- Missing share → 410
- Revoked/expired → 410
