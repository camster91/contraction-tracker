## Behavior

- The legacy default session displays “This birth” while its stored ID and name remain compatible.
- Timing labels distinguish time since the last contraction ended from spacing between starts. Invalid quick adjustments are hidden.
- Birth journey remains reachable outside the history scroll area. Its tools are grouped into Care now, Preparation and After birth, with phase context near the top.
- Supporting copy is more readable; primary sheet actions and editable fields have at least 44px targets.
- Sessions provide visible View, End session and Delete actions plus an explanation while switching is blocked by active timing.
- Care card copying uses the visible draft. Provider autosave and separately saved reminders are explained.
- Existing contacts, exams, provider questions, responsibilities and timeline entries can be edited; supporting deletion has undo.
- Contact sharing identifies a general system chooser honestly, with separate Call and Email actions. Long names and actions wrap on a narrow phone.
- User recording changes commit history and active timer together before changing the screen. Failed writes preserve the previous state and keep edit drafts available. Session, journey, contact and care-plan changes also respect persistence failures.
- History Undo occupies reserved layout space and remains available until dismissed or a subsequent recording/session change succeeds. Starting another contraction clears the previous Undo so it cannot discard the active timer.
- Global errors and confirmations render in the currently active modal's accessible tree.
- Archived journey copy explains that its details remain editable.
